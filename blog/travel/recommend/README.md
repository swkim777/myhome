# JowonPlace (조원플레이스) - 추천 여행지 감성 블로그 웹 프로그램

> **HTML, CSS, JavaScript**만을 사용하여 제작된 대중 인기 여행지 추천 및 1인칭 실감형 여행 블로그 웹 플랫폼입니다.

---

## 📌 1. 프로젝트 개요

사용자가 여행하고 싶은 도시나 지역명을 입력하면, 실시간 웹 검색 및 큐레이션 엔진을 통해 대중적으로 인기가 많은 **5대 핵심 명소(풍경, 랜드마크, 미식/카페, 문화/전통, 일몰/야경)**를 엄선하고, 마치 직접 여행을 다녀온 것처럼 생생한 1인칭 여행 블로그 포스팅으로 웹 화면에 렌더링합니다.

---

## 📂 2. 프로젝트 폴더 구조

```text
jowonplace-recommend-tour/
├── .gemini/
│   └── skills/
│       └── travel-blog-generator/
│           ├── SKILL.md                 # Antigravity 여행 블로그 자동 생성 스킬 명세
│           └── prompts/
│               └── blog_prompt_template.md # 1인칭 감성 여행기 생성 프롬프트 템플릿
├── css/
│   ├── style.css                        # 글로벌 레이아웃, 히어로, 검색창, 카드 스타일
│   └── blog.css                         # 5대 명소 타임라인, 생생 후기, 꿀팁 박스 스타일
├── js/
│   ├── data.js                          # 제주, 부산, 강릉, 경주, 교토, 방콕 등 5대 명소 큐레이션 데이터
│   ├── search.js                        # 검색 엔진, 위키피디아 API 연동 및 동적 5대 명소 블로그 생성기
│   └── app.js                           # UI 컨트롤러, 뷰 전환, 북마크, 인터랙션
├── assets/                              # 정적 리소스 디렉터리
├── index.html                           # 메인 웹페이지 (랜딩 + 검색 + 블로그 뷰)
├── ARCHITECTURE.md                      # 아키텍처 및 데이터 흐름 설계서
└── README.md                            # 프로젝트 안내 문서
```

## 🚀 3. 핵심 기능

1. **순수 Vanilla Web 기술 스택 (HTML5, CSS3, ES6+ JS)**:
   - 외부 프레임워크나 복잡한 빌드 도구 없이 브라우저에서 `index.html`을 바로 열어 동작.
2. **랜딩 페이지 및 감성 검색창**:
   - 중앙 검색창에서 원하는 국내/해외 여행지 입력 가능.
   - 원클릭 퀵 태그 제공 (#제주도, #부산, #강릉, #경주, #교토, #방콕).
3. **실시간 웹 검색 & 스마트 큐레이션**:
   - 위키피디아 오픈 API 및 테마 이미지 연동을 통해 새로운 여행지라도 5대 핵심 코스를 즉시 탐색·생성.
4. **마치 여행을 다녀온 듯한 '5대 명소 생생 블로그' 피드**:
   - **프롤로그**: 설레는 여행의 시작 에세이
   - **5대 명소 코스 타임라인 요약 바**: 원클릭 스크롤 이동
   - **스팟별 대형 블로그 카드**:
     - 📸 *포토그래퍼 인생샷 명당 스팟 꿀팁*
     - 💡 *여행자 필독 현지인 꿀팁 & 동선 안내*
     - 소요 시간, 위치, 별점 제공
   - **에필로그**: 1박 2일 추천 동선 및 여행 총평
5. **부가 기능**:
   - 나만의 여행지 로컬 스토리지 북마크 기능
   - URL 공유하기 및 인쇄/PDF 저장 기능

---

## 💻 4. 실행 방법

1. 본 저장소의 `index.html` 파일을 크롬(Chrome)이나 엣지(Edge) 등 웹 브라우저로 더블 클릭하여 실행합니다.
2. 또는 로컬 웹 서버(예: Live Server, `python -m http.server 8000`)를 통해 실행할 수 있습니다.
