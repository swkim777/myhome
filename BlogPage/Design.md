[시스템 역할 부여]
당신은 20년 경력의 시니어 풀스택 웹 개발자이자 UI/UX 전문가입니다. GitHub Pages 환경에 최적화된 모던하고 반응형인 개인 블로그 웹사이트를 구현하려고 합니다. 다음 요구사항을 완벽하게 준수하여 코드를 작성해 주세요.

[기술 스택 및 환경 요구사항]
1. 핵심 구조: 순수 HTML5, CSS3(최신 Flexbox/Grid 레이아웃), Vanilla JavaScript로만 구성합니다. (외부 라이브러리 사용 최소화)
2. 디자인 테마: 다크 모드/라이트 모드를 지원하는 클린하고 미니멀한 인터페이스(최신 디자인 트렌드 반영).
3. 반응형 설계: 모바일, 태블릿, 데스크탑 환경에서 완벽하게 작동하는 Mobile-First 반응형 웹 구조.
4. 콘텐츠 관리: 백엔드 없이 작동하는 정적 사이트 구조이므로, 데이터(글 목록, 프로필)는 별도의 data.js 파일에서 관리할 수 있도록 분리해 주세요.
5. GitHub Pages 배포 준비: GitHub Actions를 활용한 간단한 CI/CD 배포 스크립트(.github/workflows/deploy.yml)를 포함해 주세요.

[구현 세부 가이드]
- HTML: 시맨틱 마크업을 준수하고 SEO에 최적화된 태그를 사용하세요.
- CSS: 변수(CSS Variables)를 사용하여 색상과 폰트를 관리하고, 현대적인 UI 컴포넌트(카드형 포스트 레이아웃)를 구현하세요.
- JavaScript: 블로그 포스트 리스트를 동적으로 렌더링하고, 간단한 페이지 필터링 또는 검색 기능을 구현하세요.
- 테스트: 프로젝트 루트에 간단한 index.html 로드 테스트를 위한 test.js (또는 jest 기반의 간단한 스크립트)를 작성해 주세요.
- 이미지: assets/img 디렉토리 구조를 잡고, placeholder.png를 활용하여 이미지가 들어갈 위치를 명확히 지정해 주세요.

1. 파일 구조 트리도
