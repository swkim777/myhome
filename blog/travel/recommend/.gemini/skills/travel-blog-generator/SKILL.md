# Travel Blog Generator Skill (여행 블로그 콘텐츠 생성기)

## 1. 개요 (Overview)
사용자가 입력한 국내/해외 여행지에 대해 대중적 선호도가 높은 핵심 명소 5곳을 탐색하고, 독자가 현장감을 느낄 수 있는 1인칭 시점("내가 지난 주말 다녀온...")의 감성 블로그 포스팅으로 변환하여 웹사이트 데이터(`js/data.js`) 및 마크다운 파일로 구축하는 스킬입니다.

## 2. 블로그 생성 가이드라인
1. **타깃 독자**: 주말 여행, 휴가, 힐링 여행을 계획하는 20~40대 일반 대중.
2. **콘텐츠 톤앤매너**:
   - 친근하고 생생한 1인칭 대화체 (~했어요, ~추천해요, ~더군요).
   - 단순 나열식이 아닌 실제 동선(오전-점심-오후-일몰-야경)에 맞춘 현실감 있는 코스 구성.
   - 각 장소마다 **'나만의 인생샷 스팟(포토존)'**과 **'현지인 꿀팁'**, **'소요 시간 및 추천 방문 시간'**을 필수 포함.
3. **5대 명소 선정 기준**:
   - 대중적 평점 4.5 이상 또는 인스타그램/네이버/구글 리뷰 상위 핫플레이스.
   - 자연/풍경 1곳, 문화/체험 1곳, 힐링/산책 1곳, 맛집/카페거리 1곳, 일몰/야경 1곳의 균형 있는 배분.

## 3. 데이터 구조 (Schema for `js/data.js`)
```javascript
{
  id: "travel-destination-id",
  title: "여행지 명칭 (예: 제주도, 부산, 강릉)",
  subtitle: "감성 한 줄 요약 문구",
  region: "국내" | "해외",
  tag: ["#힐링", "#바다", "#인생샷"],
  heroImage: "https://images.unsplash.com/...",
  author: {
    name: "방랑여행자 민우",
    avatar: "https://images.unsplash.com/...",
    date: "2026.11.10"
  },
  introStory: "도심의 소음을 벗어나 훌쩍 떠났던 그곳...",
  spots: [
    {
      order: 1,
      name: "명소 이름",
      category: "자연/바다/카페/문화",
      rating: 4.9,
      image: "https://images.unsplash.com/...",
      shortDesc: "한 줄 특징 요약",
      story: "실제 방문 후기 스토리텔링 (2~3문단 분량)",
      photoTip: "인생샷을 건질 수 있는 위치와 각도 꿀팁",
      travelerTip: "주차, 웨이팅, 최적 시간대 정보",
      timeRequired: "1시간 30분",
      location: "상세 주소 또는 찾아가는 법"
    }
    // ... 총 5개 스팟
  ],
  epilogue: "여행을 마치며 남기는 총평과 1박2일/당일치기 추천 팁"
}
```

## 4. 실행 절차
1. 사용자로부터 여행지 이름 접수 (예: "여수", "후쿠오카", "단양").
2. 웹 검색(`search_web`)을 통해 해당 지역의 최근 인기 급상승 및 대중 선호 명소 5곳 도출.
3. 5곳의 명소별 특징과 포토스팟, 꿀팁 수집.
4. 생생한 1인칭 여행 블로그 포스팅으로 구조화.
5. `jowonplace-recommend-tour` 프로젝트의 `js/data.js`에 데이터 추가 또는 독립 마크다운 아티클 생성.
