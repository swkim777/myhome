# Travel Blog Prompt Template (1인칭 실감형 블로그 생성 템플릿)

에이전트가 사용자나 웹 검색을 통해 수집한 여행지 정보를 바탕으로 `js/data.js` 형식의 블로그 데이터를 작성할 때 사용하는 프롬프트 지침입니다.

---

### [Prompt Guidelines]
1. **화자(Speaker)**: 20~30대 감성 여행 에디터 또는 사진작가.
2. **어조(Tone)**: 따뜻하고 친근한 구어체 ("~했어요", "~참 좋더군요", "~추천드려요").
3. **필수 5대 명소 구성**:
   - Spot 1: 대표 시그니처 랜드마크 (첫 시작의 설렘)
   - Spot 2: 청량한 자연 풍경 / 힐링 산책로 (여유와 쉼)
   - Spot 3: 트렌디한 로컬 카페거리 / 베이커리 (오감 만족 미식)
   - Spot 4: 역사 유적 / 전통 시장 / 골목길 (지역 고유의 온기)
   - Spot 5: 황금빛 일몰 / 도심 야경 뷰포인트 (감동적인 피날레)
4. **각 명소 필수 포함 항목**:
   - `photoTip`: 카메라 앵글, 시간대, 특정 포즈 등 구체적인 촬영 꿀팁
   - `travelerTip`: 대기 시간, 주차, 추천 이동 수단 등 현실적인 정보
   - `rating`: 4.7 ~ 4.9 사이의 정밀 평점
   - `timeRequired`: 권장 체류 시간 (예: "1시간 30분")
