# Jowon Slide Prompt Maker

> **AI 기반 프레젠테이션 슬라이드 및 학술 가이드 프롬프트 생성 웹앱**  
> 사용자가 제시한 주제와 업로드된 PDF 문서를 바탕으로, 대상 청중의 눈높이와 선호하는 비주얼 스타일에 맞춘 최적화된 **Gemini 슬라이드 기획 프롬프트** 및 **장표별 시각 연출 지시문**을 자동으로 생성합니다.

---

## 📌 주요 특징 및 기능

### 1. 직관적인 입력 및 문서 연동
- **PDF 파일 업로드 (Drag & Drop)**:
  - 발표 자료로 변환할 PDF 문서를 드래그 앤 드롭 또는 파일 탐색기로 간편하게 업로드.
  - 업로드 완료 시 파일명, 용량 표시 및 파일명을 기반으로 한 주제 자동 추천 기능 제공.
- **주제 및 핵심 아이디어 기획**:
  - 다루고자 하는 핵심 메시지, 세미나 주제, 학습 목표를 자유롭게 작성할 수 있는 멀티라인 입력 폼.

### 2. 세분화된 맞춤형 옵션 설정
- **독자(청중) 맞춤 설정**:
  - `일반 대중(20세 이상)`: 직관적 전달, 비유와 사례, 공감대 중심 전개
  - `초등 저학년 (6~9세)`: 쉽고 친근한 시각 자료 중심 교육 가이드
  - `초등 고학년 (10~15세)`: 호기심 자극형 개념 설명 및 시각화 슬라이드
  - `대학생(원)`: 전문적 지식, 연구 배경, 메커니즘 분석 및 학술적 전개 *(기본값)*
- **8종 비주얼 아트 스타일**:
  - 수채화 및 파스텔풍, 3D 애니메이션풍, 플랫 디자인, 유화 및 클래식, 크레파스 및 스케치, 종이 오리기풍, 지브리 애니메이션풍, 마인크래프트풍 *(기본값)*
- **페이지 수 세그먼트 컨트롤**:
  - `5P`, `10P` *(기본값)*, `15P` 슬라이드 분량 선택 가능.

### 3. 고품질 프롬프트 생성 엔진
- **Gemini 시스템 프롬프트**:
  - 프레젠테이션 전략가(Presentation Strategist) 페르소나, 대상 청중 톤앤매너, 스토리 아크(도입-본론-결론)가 구조화된 마크다운 프롬프트 자동 조립.
- **페이지별 Slides 장표 뷰**:
  - 각 슬라이드별 핵심 헤드라인(`Slide 번호 및 제목`)
  - 발표 스피치 및 설명문(`📊 Slide 설명`)
  - 레이아웃 및 다이어그램 배치 지시(`🎨 Slide 비주얼 연출`)
  - 미드저니/DALL-E/Imagen 3 호환 영문 생성문(`Slide 비주얼 프롬프트 (EN)`)
- **편의 기능**:
  - **탭 연동 전체 복사**: 선택한 탭(`Gemini 시스템 프롬프트` 또는 `페이지별 Slides`)에 보이는 내용 전체를 원클릭 클립보드 복사.
  - **Markdown 다운로드**: 생성된 프롬프트를 `.md` 파일로 즉시 저장.
  - **Gemini 웹 바로가기**: 생성 프롬프트를 즉시 테스트할 수 있는 외부 링크 연동.

## 📁 프로젝트 구조

```plaintext
storybook/
├── index.html            # 웹앱 엔트리 HTML (Pretendard 폰트 및 메타데이터)

├── src/

└── dist/                 # 프로덕션 빌드 번들 결과물
```

## 🚀 실행 및 빌드 가이드

### 1. 개발 서버 실행 (수동 실행)
본 프로젝트는 사용자가 직접 터미널에서 명령어를 입력하여 실행하도록 구성되어 있습니다. 아래 명령어 중 선호하는 방식을 입력하세요.

```bash
# 옵션 1: 요청 명령어 직접 실행 (래퍼 스크립트 지원)
npm dev run

# 옵션 2: npm 표준 명령어
npm run dev

# 옵션 3: 윈도우 배치 파일 더블클릭 또는 콘솔 실행
start.bat
```
- 기본 실행 포트: `http://localhost:3000`

### 2. 프로덕션 빌드 및 프리뷰

```bash
# 프로덕션 빌드 (dist/ 폴더 생성)
npm run build

# 빌드 결과물 로컬 프리뷰
npm run preview
```
