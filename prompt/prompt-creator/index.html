THE METHOD BEHIND THE PROMPT

좋은 프롬프트의 5가지 원칙

Google의 공식 Gemini 프롬프팅 전략을 기반으로 질문과 생성 규칙을 설계했습니다.

  1. 01
    명확한 지시 (Clear Instructions) 목적과 꼭 필요한 요구사항을 구체적으로 적고 불필요한 수식어를 배제합니다.
  2. 02
    충분한 맥락 (Context & Background) 독자 대상, 배경 환경, 참고 데이터 격리 구간을 제공해 모델의 임의 추측을 줄입니다.
  3. 03
    일관된 출력 구조 (Consistent Output Format) 형식·언어·어조·분량을 사전 지정하여 결과물의 편차를 최소화합니다.
  4. 04
    원하는 결과의 예시 (Few-shot Examples) 짧은 입력과 기대 출력 한 쌍으로도 원하는 스타일과 패턴을 명확히 전달합니다.
  5. 05
    반복해서 다듬기 (Iterate & Refine) 실시간으로 미리보고 수정하며 결과물에 맞게 지침을 최적화합니다.
