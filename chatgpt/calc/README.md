# 🧮 PWA 계산기 웹앱 (Minimal Calculator)

기본적인 사칙연산을 지원하는 미니멀 계산기입니다.  
**HTML, CSS, JavaScript로 작성된 단일 페이지 앱**이며,  
**PWA(Progressive Web App)**로 설치도 가능합니다.  
모바일과 데스크탑에서 앱처럼 실행할 수 있습니다.

---

## ✨ 주요 기능

- 덧셈, 뺄셈, 곱셈, 나눗셈 연산 지원
- 버튼 기반 입력 UI
- 반응형 디자인 (모바일/PC 지원)
- `C` 버튼으로 전체 초기화
- `Exit` 버튼으로 PWA 앱 종료 시도
- PWA 지원: 홈 화면 설치 및 오프라인 사용 가능
- 서비스워커 및 manifest 설정 포함

---

## 📱 앱 설치 방법

### ✅ 모바일
1. 브라우저에서 `index.html`을 열기
2. 공유 > **"홈 화면에 추가"** 선택

### ✅ 데스크탑 (Chrome)
1. 주소창에 설치 아이콘 클릭 → 설치
2. 설치된 앱에서 `Exit` 버튼으로 창 종료 가능
